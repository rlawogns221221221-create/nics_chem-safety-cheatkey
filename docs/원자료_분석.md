## 1. 화학사고 재난문자 표준(안) — 문안의 근거

### 확정된 사실

- **화학사고는 긴급재난문자에 해당합니다.** 표준(안)의 재난문자 3단계 구분:
  - 위급재난문자 — 공습·경계·화생방 경보 / 60dB 이상 / 수신거부 불가
  - **긴급재난문자 — 자연재해·테러·화학사고 / 40dB 이상 / 수신거부 가능**
  - 안전안내문자 — 폭염·황사·폭우 등 기상특보 / 일반문자 / 수신거부 가능

  → 2026년 5월 안전안내문자 157자 확대는 **화학사고와 무관**합니다.
     이 도구는 긴급재난문자 90자를 상한으로 고정합니다.

- **송출 단위가 읍·면·동입니다.** 2023.5.25. TAC(시·군·구) → CELL(읍·면·동) 변경.
  대상지역을 읍·면·동 단위로 쓰는 것이 송출 단위와 맞습니다.

- **원칙**: "화학사고 주민대피의 기본은 외출자제 및 실내대피"

- **용어 구분** (문안 작성 시 혼용 금지)
  | 용어 | 뜻 |
  |---|---|
  | 주민대피 | 대피소로 이동하거나 실내에 머무는 것 (상위 개념) |
  | 실내대피 | 출입문·창문을 닫고 외출을 자제하며 실내에 머무는 것 |
  | 주민소산 | 사고 지역을 벗어나 지정 대피소로 이동하는 것 |
  | 대피소·집결지 | 소산·대피한 주민이 안전하게 머물며 지원받는 장소 |

### 문안 구조

6개 상황 × 2개 채널 = 12개 문안. 각 상황이 **사고발생 지역 / 그 외 지역**으로 갈립니다.

| 상황 | 사고발생 지역 | 그 외 지역 |
|---|---|---|
| 실내대피 알림 | 1(자체)·2(긴급) | 3(자체)·4(긴급) |
| 주민소산 알림 | 7·7-1(자체)·8(긴급) | 9(자체)·10(긴급) |
| 실내대피 종료 | 5(자체)·6(긴급) — 전 지역 공통 | |
| 대피명령 종료 | 11(자체)·12(긴급) — 전 지역 공통 | |

**도구의 발송 구분 3개에 어떻게 배치했는지**

| 발송 구분 | 그룹 | 문안 |
|---|---|---|
| 실내대피 알림 | 발송 문안 / 상황종료 시 문안 | 2·1 / 6·5 |
| 도로 우회 알림 | 실내대피 중일 때 / 대피명령 발령 중일 때 | 4·3 / 10·9 |
| 주민소산(대피명령) 알림 | 발송 문안 / 상황종료 시 문안 | 8·7·7-1 / 12·11 |

원자료의 상황 구분(4개)을 그대로 화면에 옮기지 않은 이유:

- **종료 문안을 별도 항목으로 두면 사고정보를 다시 입력해야 합니다.** 같은 사고이므로
  알림 문안과 종료 문안을 한 구분 안에서 함께 만들고, 상황이 끝났을 때 골라 쓰게 했습니다.
- **사고발생 외 지역용(3·4·9·10번)은 성격이 다릅니다.** 사고지역 주민이 아니라 통행 차량과
  인접지역 주민에게 "이 지역을 피해 우회하라"고 알리는 문안이며, 대피장소 입력이 필요 없습니다.
  → 실내대피 중이든 대피명령 중이든 **「도로 우회 알림」 하나로 묶었습니다.**
- 근무자가 사고지역용만 보내고 외지역용을 놓치는 것을 막기 위해 **긴급재난문자용과
  자체 시스템용을 항상 함께 생성**하는 원칙은 그대로 유지했습니다.

한 화면에 단계가 다른 문안이 함께 나오므로, 실내대피↔외부대피 표현 혼재 검사는
화면에서 고른 구분이 아니라 **문안 하나하나의 `단계` 값으로** 수행합니다.

## 2. 실제 발송 사례 42건 — 도구가 풀어야 할 문제의 실측

| 항목 | 값 |
|---|---|
| 길이 최소 / 최대 | 61자 / 130자 |
| 평균 / 중앙값 | **85.5자 / 88자** |
| 90자 초과 | 2건 (정확히 90자로 끝나 잘린 것으로 보이는 사례 2건 별도) |

### 확인된 것

**① 실사용 문안은 90자 경계에 몰려 있습니다.** 중앙값 88자는 여유가 2자라는 뜻입니다.
   축약 기능은 예외 처리가 아니라 **상시 작동하는 기능**으로 봐야 합니다.

**② 표준(안) 문안을 예시값 그대로 채우면 90자를 넘습니다.**

| 문안 | 예시값 기준 길이 |
|---|---|
| 2번 (실내대피·사고지역) | **110자** |
| 8번 (주민소산·사고지역) | **123자** |
| 10번 (주민소산·외지역) | **94자** |
| 4·6·12번 | 80·85·87자 |

→ **표준(안)이 있어도 근무자가 그대로 쓸 수 없는 이유가 여기 있습니다.**
   이 도구의 핵심 가치는 "표준(안)을 90자 안으로 정확히 압축하는 것"입니다.

**③ 표기 관행이 표준(안)과 다릅니다.**
   - 기관명을 문구 **끝**에 두는 사례가 많음 (`… [서천군]`)
   - `금일` 대신 `오늘`, `어제` 사용
   - 물질명 없이 `화학물질`, `유독가스`, `미세가스`로만 쓴 사례 다수
   - 같은 사고에서 대피장소를 정정하는 후속 문자 (`-대피장소정정-`)

**④ 단계 분포** — 실내대피 20건, 상황종료·경과 10건, 주민소산 9건, 차량우회 1건, 기타 2건.
   실내대피와 종료 문자가 전체의 71%입니다. 도구가 이 두 단계를 가장 매끄럽게 지원해야 합니다.

### 사용 방침

사례는 도구 안에 **참고 자료(비승인)** 로만 넣었습니다. 표준문안으로 쓰지 않습니다.
오탈자(`바랍니. `), 조사 오류, 지역 불명확 표기가 실제로 포함되어 있습니다.

## 4. 화학사고 현장대응 물질정보 460종 — 물질별 참고정보의 근거

원자료: `source/화학사고_현장대응_물질정보_460종_2026.hwpx` (18MB, 표 3,681개)

### 추출 결과

HWPX는 한글 문서를 압축한 형식이라 표의 셀 주소를 보존해야 항목-값 대응이 깨지지 않습니다.
`build/hwpx.py` 로 셀 주소 기반 파서를 만들고, `build/extract_mat.py` 로 물질별로 잘랐습니다.

물질 1종당 표 8개(표제 / 물질 기본정보 / NFPA / 개인보호구 / 대응 방법 /
작업장 허용 노출기준 / 인체노출 유해성·증상 / 응급조치) 구성입니다.

| 항목 | 추출률 |
|---|---|
| 물질명 · CAS · 성상 · 대응방법 · 증상 · 응급조치 | 460/460 (100%) |
| 화재대피거리 | 460/460 (100%) |
| 비중 · 증기밀도 · 초기이격거리 · 방호활동거리 · ERG · UN · GHS | 458~459/460 (99%) |
| 화재·폭발 가능성 | 455/460 (98%) |
| NFPA | 353/460 (76%) |

NFPA 미추출 107종은 **원문에 `-` 로 비어 있는 것**이며 파싱 실패가 아닙니다.

### 물질명은 목록표(첫 번째 표)가 정본입니다

물질별 상세 페이지의 표제는 `염소, 클로로(Chlorine, Cloro)` 처럼 동의어가 붙어 있지만,
문서 맨 앞 목록표(순서·물질명·CAS No·쪽번호, 460행)에는 `염소` 로 깔끔하게 실려 있습니다.
**CAS 로 연결해 목록표 이름을 표시명으로 씁니다.** 표제명과 국문유사명은 검색용 별칭으로만 둡니다.

> **한 번 크게 틀렸던 부분 — 쉼표로 이름을 자르지 말 것**
>
> 표제의 `염소, 클로로` 를 정리하려고 쉼표로 잘랐다가 화학명 34건이 깨졌습니다.
> `1,1-디클로로에틸렌` → `1`, `N,N-디메틸포름아미드` → `N`,
> `황산, 알루미늄 칼륨 염(2:1:1), 도데카하이드레이트` → `황산`(진짜 황산과 중복).
> 화학명에는 쉼표가 정상적으로 들어갑니다. **분리하지 않습니다.**
>
> 국문유사명도 같습니다. 세미콜론이 있으면 그것으로 나누고,
> 없을 때만 `쉼표 + 뒤가 숫자가 아닌 경우` 에 한해 나눕니다.

남은 동명이인은 **`인` 2건**뿐이며, 이는 원문 목록표에도 백린(12185-10-3)과
적린·황린(7723-14-0)이 모두 `인` 으로 실려 있는 것입니다. 화면에서는 영문명과 CAS 로 구분됩니다.

### 사고빈도는 정식 이름으로만 대조합니다

물질 목록을 사고 발생빈도순으로 정렬하는데, 별칭까지 대조하면 오염됩니다.
`황산 마그네슘` 의 유사명에 `황산` 이 들어 있어 황산의 95건을 가져가는 식입니다.
표시명과 `/` 로 구분된 동의어(`염화수소/염산` → `염화수소`, `염산`)까지만 대조합니다.

### 도구에 넣은 것 / 뺀 것

이 자료는 **현장대응요원용**입니다. 개인보호구 등급(Lv A/B/C), 탐지장비 모델명,
중화제 종류 같은 항목은 주민 문자와 무관하므로 제외했습니다.

**넣은 것** — 성상·냄새(주민 인지 단서), 증기밀도(저지대 체류 여부), 비중,
인화점·폭발한계, 화재·폭발 가능성, NFPA 건강위험도, 거리 3종, 흡입 증상,
응급조치(흡입·피부·눈).

### 사고유형에 따라 달라지는 거리 — 질문의 답

「대응 방법」 표에 사고 상황별로 다른 거리가 규정돼 있습니다. 도구는 선택한
사고유형에 맞는 거리만 보여줍니다.

| 사고유형 | 표시하는 거리 | 성격 |
|---|---|---|
| 누출 | **초기이격거리** | 전 방향, 즉시. 예) 염소 소규모 60m / 대규모 1km |
| 누출 | **방호활동거리** | 풍하방향, 낮·밤 구분. 예) 염소 대규모 낮 10.1km / 밤 11km |
| 화재·폭발 | **화재 동반 시 대피거리** | 전 방향 반경. 예) 염소 0.8km |

낮과 밤 값이 크게 다른 것(염소 소규모 낮 0.3km / 밤 1.4km)은 야간 대기 안정도 때문입니다.
**야간 사고에서 대상지역을 낮 기준으로 잡으면 과소 설정이 됩니다.**

> 다만 이 값들은 **참고 표시일 뿐** 도구가 대상지역을 계산하지 않습니다.
> 지시받은 대상지역이 타당한지 담당자가 대조하는 용도입니다.

## 5. 화학사고 통계 2015~2025 — 사고유형 구분의 근거

원자료: `source/화학사고_통계_2015-2025.xls` (사고 1,038건, 25개 컬럼)

### 사고유형은 4종으로 확정돼 있습니다

| 유형 | 건수 | 비율 |
|---|---|---|
| 누출 | 810 | 78.0% |
| 화재 | 80 | 7.7% |
| 폭발 | 74 | 7.1% |
| 기타 | 74 | 7.1% |

도구의 사고유형 선택지는 이 공식 분류를 그대로 씁니다. 임의로 만든 구분이 아닙니다.

- **사고원인**도 4종입니다: 안전기준 미준수 482 / 시설 결함 367 / 운송차량 179 / 자연재해 10.
  (현재 도구는 사용하지 않습니다. 문자 문안에 들어가지 않는 항목입니다.)
- **연도별 추이**: 2019년 58건으로 저점 → 2023년 116 → 2024년 128 → **2025년 155건**.
  최근 3년 증가세가 뚜렷합니다.

### 물질별 빈도 — 입력칸 정렬에 사용

제1사고물질 454종 중 상위: 염산 101 · 황산 95 · 암모니아 87 · 질산 78 ·
수산화나트륨 41 · 톨루엔 29 · 과산화수소 22 · 염소 20.

물질 입력칸의 자동완성 목록을 이 빈도순으로 정렬해, 자주 발생하는 물질이 위에 오게 했습니다.
농도 표기(`염산(35%)`)는 기본 물질명으로 합쳐 집계했습니다.

> **통계로 판단하지 않습니다.** 입력 편의를 위한 정렬과 사고유형 구분 근거로만 씁니다.
