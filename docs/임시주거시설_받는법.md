# 이재민 임시주거시설 자료 받는 법 — 2분

② 주민 대피장소 찾기에 **이재민 임시주거시설 층**을 켜려면 자료 파일
`data/tempshelters.js` 하나가 필요합니다. 화면 코드는 다 되어 있고
**만 곳 규모까지 미리 재 두었습니다**(`tests/run.sh tmpbig`). 자료만 없습니다.

**결론부터** — 이 자료는 **국내 IP 에서만** 받아집니다. 그래서 사무실 PC 에서
한 번 받아야 하고, 그 일은 아래 두 걸음입니다.

---

## 1. 인증키에 IP 를 등록합니다 (한 번만)

`safetydata.go.kr` 로그인 → **마이페이지** → **오픈API 활용신청 현황** →
이재민 임시주거시설 API → **활용 IP(서버 IP)** 에 **그 PC 의 IP** 를 넣습니다.

- 제한 없음으로 둘 수 있으면 그렇게 두는 것이 편합니다.
- 지금 그 PC 의 IP 는 검색창에 `내 아이피` 를 치면 나옵니다.

> **왜 필요한가** — 2026-09-07 에 실제로 불러 봤더니 서버가
> `32 UNREGISTERED IP ERROR` 로 답했습니다. 인증키는 살아 있고 네트워크도
> 뚫렸는데, **활용신청 때 적어 둔 IP 에서만** 받아 주는 자료입니다.

## 2. 페이지를 엽니다

저장소 폴더의 **`build/fetch_tempshelter.html`** 을 그 PC 의 브라우저로 엽니다
(더블클릭). 열면 저절로 받아옵니다.

1. 다 받으면 **`tempshelters.js` 내려받기** 단추가 생깁니다
2. 받은 파일을 저장소의 **`data/`** 폴더에 넣습니다
3. 끝입니다 — ② 화면을 열면 임시주거시설 층이 보입니다

**저에게 파일을 붙여 주셔도 됩니다.** 그러면 제가 넣고
`python3 build/build_single.py` 까지 돌려 놓습니다.

---

## 파일로 받는 길 (페이지가 안 될 때)

플랫폼 화면에서 목록을 **파일로 내려받아** 넘겨 주시면 같은 결과가 됩니다.

```bash
python3 build/make_tempshelters.py 받은것.json    # csv · xlsx 도 됩니다
```

이 길이 **더 확실합니다** — 파일을 받으면 **칸 이름을 제가 직접 보고** 맞출 수
있습니다. 지금은 그 서버로 나갈 수 없어 칸 이름을 짐작으로 짝지어 두었습니다
(영문 약어 `FCLT_NM`·`RONA_DADDR`·`LAT`·`LOT` 등을 규칙에 넣어 두었고, 페이지가
짝지은 결과와 원자료 첫 줄을 그대로 띄웁니다).

---

## 왜 제가 대신 못 받나 — 두 번 확인했습니다

| 어디서 | 결과 |
|---|---|
| 개발 자리(이 저장소를 만드는 곳) | 게이트웨이가 `safetydata.go.kr`·`data.go.kr` 로 나가는 것을 **403 으로 막습니다** |
| 깃허브 액션 러너(인터넷 됨) | `safetydata.go.kr` 은 **닿지만** 인증키가 IP 제한 → `32 UNREGISTERED IP ERROR`<br>`data.go.kr` 은 **아예 시간초과** — 러너가 미국(Azure)에 있어 막히는 것으로 보입니다 |

러너 IP 는 돌 때마다 달라(그날 `172.215.210.49`) 등록해 둘 수도 없습니다.
**국내 IP 에서 한 번 받는 것**이 유일한 길입니다.

> 참고 — 받아 오는 길은 셋 다 만들어 두었습니다.
> · `build/fetch_tempshelter.html` 사람이 브라우저에서 누르는 길
> · `build/fetch_tempshelter.py` 명령줄에서 돌리는 길(같은 규칙을 씁니다)
> · `.github/workflows/임시주거시설_받기.yml` 깃허브 액션에서 돌리는 길
>   (IP 제한이 풀리면 Actions → Run workflow 한 번으로 끝납니다)

## 자료가 들어오면 할 일

```bash
tests/run.sh tmp2 tmpbig     # 층이 제대로 나오는가 · 규모를 버티는가
python3 build/build_single.py # 망분리 PC용 단일 파일에도 넣기
```

`data/tempshelters.js` 는 **있으면 쓰고 없으면 그 층만 빠지는** 선택 파일입니다
(`build_single.py`·`make_release.py` 의 `OPTIONAL`). 그래서 지금처럼 없어도
나머지는 그대로 돕니다 — 고장이 아닙니다.
