# 이재민 임시주거시설 자료 받는 법

> **✔ 2026-09-08 에 받아 넣었습니다 — `data/tempshelters.js` 15,905곳.**
> 이 글은 이제 **자료를 새로 받을 때** 보는 것입니다.
> 갱신주기는 `1일` 이지만, 시범운영 중에는 **몇 달에 한 번**이면 충분합니다
> (시설 목록이 하루아침에 크게 바뀌지는 않습니다). 화면에는 **자료 기준일**이
> 적혀 있으니, 오래되었다 싶을 때 아래대로 다시 받으면 됩니다.

② 주민 대피장소 찾기의 **이재민 임시주거시설 층**은 자료 파일
`data/tempshelters.js` 로 돕니다.

**이 자료는 인증키에 등록된 IP 에서만** 받아집니다. 그래서 사무실 PC 에서
받아야 하고, 그 일은 아래 두 걸음입니다.

---

## 1. 인증키에 IP 가 등록되어 있는지 봅니다 (한 번만 하면 됩니다)

`safetydata.go.kr` 로그인 → **마이페이지** → **오픈API 활용신청 현황** →
이재민 임시주거시설 API → **활용 IP(서버 IP)** 에 **그 PC 의 IP** 를 넣습니다.

- 제한 없음으로 둘 수 있으면 그렇게 두는 것이 편합니다.
- 지금 그 PC 의 IP 는 검색창에 `내 아이피` 를 치면 나옵니다.

> **왜 필요한가** — 2026-09-07 에 실제로 불러 봤더니 서버가
> `32 UNREGISTERED IP ERROR` 로 답했습니다. 인증키는 살아 있고 네트워크도
> 뚫렸는데, **활용신청 때 적어 둔 IP 에서만** 받아 주는 자료입니다.

## 2. 페이지를 엽니다

**`build/fetch_tempshelter.html`** 을 그 PC 의 브라우저로 엽니다(더블클릭).
열면 저절로 받아옵니다 — **1,000줄씩 16번**을 알아서 넘깁니다.

1. 다 받으면 **`tempshelters.js` 내려받기** 단추가 생깁니다
2. 받은 파일을 저장소의 **`data/`** 폴더에 넣습니다
3. 끝입니다 — ② 화면을 열면 임시주거시설 층이 보입니다

**저에게 파일을 붙여 주셔도 됩니다.** 그러면 제가 넣고
`python3 build/build_single.py` 까지 돌려 놓습니다.

> 다운로드 폴더에 혼자 두고 열어도 됩니다 — 지역 이름표를 페이지 안에
> 박아 두어서 결과가 같습니다.

### 페이지가 막힐 때 (브라우저 보안 · CORS)

주소창으로는 되는데 페이지에서만 안 되면, 주소창에서 **쪽마다 저장**하면 됩니다.

```
https://www.safetydata.go.kr/V2/api/DSSP-IF-10945?serviceKey=<인증키>&pageNo=1&numOfRows=1000&returnType=json
```

`pageNo=1` 부터 **16까지** 바꿔 가며 `Ctrl+S` 로 저장한 뒤, 페이지의
**‘내려받아 둔 JSON 파일로 하기’** 로 **16개를 한꺼번에** 고르세요.
겹쳐 저장한 줄은 알아서 걸러냅니다.

⚠ **`numOfRows` 를 더 크게 넣어도 소용없습니다** — 서버가 **1000 으로 깎아서**
돌려줍니다(확인함). 총 15,911건 ÷ 1,000 = 16쪽입니다.

## 파일로 받는 길 (페이지가 안 될 때)

플랫폼 화면에서 목록을 **파일로 내려받아** 넘겨 주시면 같은 결과가 됩니다.

```bash
python3 build/make_tempshelters.py 받은것.json    # csv · xlsx 도 됩니다
```

**칸 이름은 2026-09-08 에 확인했습니다** — 사용자가 실제 응답을 보내 주어
`VT_ACMDFCLTY_NM`(시설명) · `DTL_ADRES`(주소) · `LA`/`LO`(좌표) ·
`VT_ACMD_PSBL_NMPR`(수용인원) · `FCLTY_AR`(면적)로 맞췄습니다.
짐작으로 두었던 **수용인원과 시도 규칙이 틀려 있어** 고쳤습니다.

**이 자료에 없는 것 — 비워 둡니다.** 관리기관·전화번호가 **아예 없고**,
시설구분은 뜻이 적히지 않은 코드(`001`·`003` …)뿐입니다. 지어내면 담당자가
틀린 곳으로 전화를 겁니다. 코드표를 받으면 시설구분은 그때 채웁니다.

## 왜 제가 대신 못 받나 — 두 번 확인했습니다

| 어디서 | 결과 |
|---|---|
| 개발 자리(이 저장소를 만드는 곳) | 게이트웨이가 `safetydata.go.kr`·`data.go.kr` 로 나가는 것을 **403 으로 막습니다** |
| 깃허브 액션 러너(인터넷 됨) | `safetydata.go.kr` 은 **닿지만** 인증키가 IP 제한 → `32 UNREGISTERED IP ERROR`<br>`data.go.kr` 은 **아예 시간초과** — 러너가 미국(Azure)에 있어 막히는 것으로 보입니다 |

러너 IP 는 돌 때마다 달라(그날 `172.215.210.49`) 등록해 둘 수도 없습니다.
**국내 IP 에서 한 번 받는 것**이 유일한 길입니다.

> 참고 — 받아 오는 길은 셋 다 만들어 두었습니다.
> · `build/fetch_tempshelter.html` 사람이 브라우저에서 누르는 길
> · `build/fetch_tempshelter.py` 명령줄에서 돌리는 길(같은 규칙을 씁니다)
> · `.github/workflows/임시주거시설_받기.yml` 깃허브 액션에서 돌리는 길
>   (IP 제한이 풀리면 Actions → Run workflow 한 번으로 끝납니다)
