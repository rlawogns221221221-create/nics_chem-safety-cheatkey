&nbsp;&nbsp;- 도구 하나를 **HTML 파일 한 개**로 합치는 변환을 만들어, 인터넷이 없는 PC에서도 파일을 열기만 하면 그대로 동작

○ **(성공요인) "도구는 판단하지 않는다"는 원칙을 코드와 검증으로 못 박음**
&nbsp;&nbsp;- 화학사고 대피장소는 공식적으로 **"최소한의 선정기준이며 지자체장이 지역여건을 고려해 탄력적으로 적용"** 하는 것 — 도구가 적합·부적합을 판정하면 **책임 소재가 흐려지고 오히려 위험**
&nbsp;&nbsp;- 어림값에는 「대략」을 표시하고, 확인 못 한 값은 비워 두며, 화면에 새로운 단정을 얹지 않도록 자동 검증이 상시 감시
