> **공공 GitLab(gitlab.aigov.go.kr) 화면은 이 개발 환경에서 열어 볼 수 없어 확인하지 못했습니다** —
> 단추 이름이 조금 다를 수 있습니다.

## 올릴 것

`release/공모전_GitLab.zip` (보내 드린 파일) — 압축을 풀면 `화학사고_초동대응_지원_서비스/` 폴더 하나가 나옵니다.
**그 폴더 안의 것들**(README.md · index.html · assets · data · dist · docs · …)을 프로젝트 맨 위에 올립니다.
폴더째 한 단계 더 넣지 마세요 — README 가 프로젝트 첫 화면에 보이려면 맨 위에 있어야 합니다.

## 차례 (마감 11.11 · 마감 뒤에는 고치면 안 됨)

1. **회원가입** — https://gitlab.aigov.go.kr
2. **새 프로젝트 만들기** — 「New project」 → 「Create blank project」
   - 이름: `화학사고 초동대응 지원 서비스` (주소용 이름은 영문으로 자동 생성되면 그대로 둠)
   - **공개 범위: 비공개(Private)** — 심사위원 열람용(공고 ②)
   - 「Initialize repository with a README」 는 **끄기**(우리 README 를 올립니다)
3. **주제(Topics)** — 프로젝트 「Settings → General」 → Topics 에서 **`2026 공공 AI 대전환 챌린지 세션1`** 고르기 → 저장(공고 ③)
4. **프로젝트 주소를 복사해 알려 주세요.** 팀명과 함께 주시면 구동안내서에 넣어 다시 굽고,
   그 구동안내서가 든 묶음을 다시 만들어 드립니다(1~2분). **그다음에 5번을 한 번에** 하는 것이 깔끔합니다.
5. **파일 올리기** — 파일이 117개라 하나씩 올리기는 어렵습니다. 둘 중 편한 것으로:
   - **Web IDE** — 프로젝트 화면의 「Edit → Web IDE」(또는 키보드 `.`) → 왼쪽 파일 목록에
     압축을 푼 폴더 **안의 것들을 끌어다 놓기** → 왼쪽 「Source Control」 → 메시지 `제출` → 「Commit to main」
   - **Git 명령** (PC 에 Git 이 있으면)
     ```bash
     git clone <프로젝트 주소>
     # 압축을 푼 폴더 안의 것들을 clone 한 폴더로 복사한 뒤
     git add . && git commit -m "제출" && git push
     ```
6. **확인** — 프로젝트 첫 화면 아래에 README(화면 사진 6장이 든 소개)가 보이는지, `dist/` 에 HTML 4개가 있는지.
7. **참가신청서에 프로젝트 주소 적기**(공고 ⑤) → 메일 제출.
