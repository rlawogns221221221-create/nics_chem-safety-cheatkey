# 화학사고 초동대응 지원 서비스

**2026 공공 AI 대전환 챌린지 · 세션 1 (자유주제) 출품작**

화학사고가 나면 지자체 담당자가 **휴대전화 하나로**, 사고지점에서 가까운 순으로
① 주민 대피장소를 찾고, ② 주민대피 재난문자를 승인 표준문안 그대로 만들고,
③ 방제 물품·장비를 가진 곳(업체 섭외 · 방제물품)을 찾는 웹 서비스입니다.

- **접속 주소**: https://chem-safety-kr.pages.dev (휴대전화·PC 브라우저 — 설치·회원가입 없음)
- **구동 안내서**: `구동안내서.pdf` · **휴대전화 사용 설명서**: `휴대전화_사용설명서.pdf`
- **시연영상**: 메일로 제출한 `[시연영상]_….mp4` (휴대전화 화면 · 예시 상황 · 업체명·전화번호는 흐리게 가림)

---

## 주요 기능

| 첫 화면 카드 | 하는 일 |
|---|---|
| **01 주민 대피장소 찾기** | 화학사고 대피장소(1,849곳)와 이재민 임시주거시설(15,905곳)을 두 층으로. 가장 가까운 곳 · 반경 1·2·5km 개수 · 도보시간 · 수용인원. 고른 곳을 **「이 내용으로 문자 만들기」**로 02 에 넘김 |
| **02 주민대피 문자생성기** | 알림 종류(실내대피·도로 우회·주민소산)를 고르고 **한 화면에 한 가지씩** 채우면 승인 표준문안 그대로 문안 + 글자수 → 복사. 필수 칸이 비면 문안을 만들지 않음 |
| **03 방제 물품·장비 찾기** | 「업체 섭외」(폐기물·폐수를 맡길 곳 · 중장비 · 독성가스 회수) / 「방제물품 찾기」(흡착포·보호구 등 표준 27가지) 중 고르고 사고지점을 넣으면, 가까운 순으로 **보유 수량 · 연락처**. 줄을 누르면 전화번호가 가장 크게 |

**원칙** — 서비스는 판단하지 않습니다(어디로 대피시킬지는 담당자가 정함) ·
어림값은 어림값이라고 표시 · 없는 값은 지어내지 않음 · 개인정보(업체 담당자
실명·휴대전화) 제외 — 대표번호·부서번호만.

## 실행·작동 방법

1. **바로 쓰기** — 휴대전화 카메라로 QR 또는 https://chem-safety-kr.pages.dev 열기 → 카드 01 대피장소 · 02 문자 · 03 방제
2. **이 저장소로** — 내려받아 `index.html` 을 더블클릭(파일로 바로 열림).
   또는 이 폴더에서 `python3 -m http.server 8000` → http://localhost:8000
3. **인터넷이 안 되는 업무망 PC** — `dist/` 의 단일 HTML 3개 중 하나를 더블클릭(실행물)
4. **화면 자동 검증(선택)** — `tests/run.sh` (Node + Playwright 필요. 실제 크로미움으로 화면을 눌러 보는 19묶음)

- 서버·DB·빌드 도구·외부 라이브러리 없음. 정적 파일만으로 동작합니다.
- 인터넷이 있을 때만 더해지는 것: 배경지도(브이월드 → OpenStreetMap 자동 전환) · 주소·장소 검색(브이월드) · 도보 경로(OSRM). 없으면 그 기능만 빠집니다.
- **LLM 연결 설정: 해당 없음** — 실행 중 AI 모델을 부르지 않습니다(키 입력 없이 구동). AI 는 개발(AI 코딩 도구로 담당 공무원이 직접 개발)과 원자료 정리에 썼습니다.

## 폴더

```
index.html            첫 화면 (카드 01·02·03)
map/ sms/ res/        01 주민 대피장소 · 02 주민대피 문자 · 03 방제 물품·장비
assets/               공용 스타일·지도 엔진·인터넷 기능(online.js — 없어도 나머지는 동작)
data/                 화면이 읽는 자료(기계 생성) — 기준일은 각 화면에 표시
dist/                 업무망 PC용 단일 HTML 3개
build/                자료 생성·단일 파일·시연영상·서류 스크립트(원자료는 이 묶음에 없음)
tests/                화면 자동 검증
```
