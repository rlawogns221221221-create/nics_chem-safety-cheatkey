## 1. 바로 써 보기 — 심사위원 구동 순서

**가장 쉬운 길** — 휴대전화 카메라로 시연영상 끝의 QR을 비추거나, 브라우저에서 **https://chem-safety-kr.pages.dev** 를 엽니다.

**이 저장소로** — 내려받아 뿌리의 `index.html` 을 더블클릭하면 그대로 열립니다(서버 필요 없음).
또는 이 폴더에서 `python3 -m http.server 8000` → http://localhost:8000

**업무망 PC(인터넷 없음)** — `dist/` 의 파일 하나를 더블클릭합니다. 지도·자료·검색이 파일 안에 다 들어 있습니다.

### 1분씩 따라 해 보기 (시연영상과 같은 예시 · 실제 사고 아님)

| 카드 | 이렇게 눌러 보세요 | 확인할 것 |
|---|---|---|
| **01 주민 대피장소 찾기** | 주소 칸에 `여수시 주삼동` → 목록에서 고르기 → **지도를 한 번 눌러** 사고지점 확정 | 가장 가까운 대피장소 · 반경 1·2·5km 안 개수 · 「이 내용으로 문자 만들기」 |
| **02 주민대피 문자생성기** | `실내대피 알림` → 한 화면에 한 가지씩 채우기(물질 `암모니아`) | 승인 표준문안 그대로의 문안 · 글자수 · **빈칸이 있으면 문안을 만들지 않음** |
| **03 방제 물품·장비 찾기** | `방제물품 찾기` → `흡착포` → 사고지점 칸에 `여수시` → `삼동2길` 이 든 주소 고르기 | 가까운 순 보유처 · 수량 · 줄을 누르면 **전화번호가 가장 크게** |
| **04 현장 안전거리 확인** | 물질 `암모니아` → 지도에서 사고지점 찍기 → `대규모` → 바람 `남서` → 「내 위치 확인」 | 초기이격 원 · 방호활동 구역 · **내 위치가 구역 안인지** · 「상황 공유」 링크 |

PC에서 04의 「내 위치 확인」은 PC 위치로 잡히므로, **지도를 누르면 그 자리가 구역 안인지** 같은 방식으로 확인할 수 있습니다.

## 2. 왜 만들었나 — 현장의 문제

화학사고 초동대응에서 지자체 담당자가 하는 일은 넷입니다. 그런데 필요한 자료가 흩어져 있습니다.

| 해야 할 일 | 지금까지의 어려움 | 이 서비스 |
|---|---|---|
| ① 주민을 어디로 | 대피장소 목록(1,849곳)과 이재민 임시주거시설(15,905곳)이 따로 있어, 사고지점 기준으로 함께 가까운 순으로 보기 어려움 | 사고지점 하나 → 두 층을 나눠 **가까운 순 · 반경별 개수 · 도보시간** |
| ② 주민에게 알리기 | 재난문자 표준문안(안)을 손으로 채우다 빈칸·오타가 남을 수 있음 | **한 화면에 한 가지씩** 묻고, 필수 칸이 다 차야만 **표준문안 그대로** 문안 |
| ③ 방제 자원 구하기 | 방제자원 원자료가 **3,865곳 · 8,266줄**, 엑셀·한글·PDF·**스캔 허가증**으로 기관마다 흩어짐 | **업체 섭외 1,717건 · 방제물품 4,075건(자리 2,341곳)** 으로 묶어 가까운 순 · 연락처 · 수량 |
| ④ 내가 선 자리는 | 물질별 초기이격·방호활동 거리는 물질정보에 글로 적혀 있어, 현장에서 바람·내 위치와 바로 견주기 어려움 | 물질 **460종의 ERG 거리**를 지도 구역으로 그리고 **내 위치가 안인지 계속** 표시 |

- **실제 사고 대응에 활용 5명**

## 3. 무엇이 다른가

1. **사고지점 하나로 네 업무가 이어집니다.** 01에서 고른 대피장소가 02 문자의 칸으로 그대로 넘어가고,
   04에서 정한 사고지점·물질이 01·02로 넘어갑니다. 같은 값을 네 번 치지 않습니다.
2. **문자는 "만드는" 것이 아니라 "승인된 문안을 채우는" 것입니다.** 문장을 조립하거나 생성하지 않고,
   빈 필수 칸이 있으면 문안 자체를 내놓지 않습니다 — 반쪽 문안이 그대로 발송될 위험을 막습니다.
3. **물질정보의 글을 지도 위 구역으로.** 「화학사고 현장대응 물질정보」 460종에 글로 적힌 ERG 거리
   (육지/수계 · 기체/액체 · 소·대규모 · 낮·밤 등 표기가 물질마다 다름)를 숫자로 읽어 그립니다.
   **460종 전부, 원문의 숫자 개수와 읽은 개수를 기계로 대조**합니다. 낮·밤은 사고지점의 일출·일몰로 정합니다.
4. **서버 없는 상황 공유.** 04의 「상황 공유」는 물질·사고지점·조건을 **링크 하나**에 담아 문자·메신저로
   보냅니다. 받은 사람이 열면 같은 구역이 그려집니다. 서버·계정·DB가 없고, **보낸 사람의 내 위치는 담지 않습니다.**
5. **인터넷이 끊겨도.** 같은 기능을 **파일 하나**로 업무망 PC에서 엽니다(자료·지도 경계선·검색 색인 포함).
6. **휴대전화가 먼저.** 현장에서 꺼내 쓰는 도구라 390px 화면에서 먼저 맞추고, 손가락으로 누르는 것은 40px 이상,
   고대비(어두운) 화면과 화면낭독기를 지원합니다(정부 디자인 시스템 KRDS 토큰).

### AI를 어떻게 썼나

**만드는 데 AI를 썼고, 판단은 사람이 합니다.**

- **개발** — 전문 개발자가 아닌 **담당 공무원이 AI 코딩 도구(Claude Code)와 대화하며 직접** 만들었습니다.
  화면 코드, 자료 변환 스크립트, 자동 검증 20묶음까지 모두 이 방식입니다.
- **자료 정리** — 흩어진 원자료를 AI로 정리했습니다. 자세한 것은 [자료 정리와 AI 활용](docs/자료_정리와_AI활용.md).
  - 스캔 이미지뿐인 **폐기물처리 허가증 24건을 판독**해 허가 갈래·처리가능 폐기물·주소·대표번호를 표로
  - 한 표에서만 **484가지**로 적힌 방제물품 이름을 급할 때 부르는 단위의 **표준 27가지**로 (원래 이름은 남김)
  - 원자료에 섞여 있던 **담당자 실명 2,719건 · 개인 휴대전화 495건을 걷어냄** — 배포할 때 기계로 다시 검사
  - 물질 460종의 ERG 거리 글을 숫자로 읽는 규칙을 만들고 **460종 전수 대조**
- **실행 중에는 AI 모델을 부르지 않습니다** — 일부러 그렇게 정했습니다.
  ① 재난문자는 **승인 표준문안만** 나가야 하고 ② 인터넷이 끊긴 **업무망 PC에서도 같은 결과**가 나와야 하며
  ③ 사고 현장에서 **응답 지연·장애 없이 몇 초 안에** 결과가 나와야 하기 때문입니다.

### 믿을 수 있게 — 지키는 원칙

| 원칙 | 화면에서 | 어떻게 지키나 |
|---|---|---|
| 서비스는 판단하지 않습니다 | 어느 대피장소·업체로 할지는 담당자가 정함. 04는 「초기이격거리 안 · 방호활동 구역 안 · 두 구역 밖」 같은 **사실만** | 「위험합니다·안전합니다」 같은 단정이 화면에 나오면 실패(`tests/safe`) |
| 어림값은 어림값이라고 | 직선거리·도보시간 어림, 주소로 잡은 좌표는 **속이 빈 마커** · `(대략)` | 어림 좌표로는 사고지점을 저절로 찍지 않고, 지도를 한 번 눌러야 확정 |
| 없는 값은 지어내지 않음 | 전화번호가 없으면 비움 · 물질정보에 없는 조합은 「자료에 없음」(다른 값 빌려 오지 않음) | 460종 거리 전수 대조 · 자료와 화면 건수 대조 |
| 개인정보 제외 | 업체 담당자 실명·휴대전화 없음 — 대표번호·부서번호만 | `build/make_release.py` 가 걸리면 배포 폴더를 만들지 않음 |

## 4. 네 가지 기능

| 카드 | 하는 일 |
|---|---|
| **01 주민 대피장소 찾기** | 화학사고 대피장소(1,849곳)와 이재민 임시주거시설(15,905곳)을 **두 층**으로(비상구 그림 / 집 그림 — 색을 못 가려도 구별). 가장 가까운 곳 · 반경 1·2·5km 개수 · 도보시간 · 수용인원 · 길찾기(카카오맵·네이버지도). 고른 곳을 「이 내용으로 문자 만들기」로 02에 넘김 |
| **02 주민대피 문자생성기** | 알림 종류(실내대피 · 도로 우회 · 주민소산(대피명령))를 고르고 **한 화면에 한 가지씩** 채우면 승인 표준문안 그대로 문안 + 글자수 → 복사. 사고물질은 460종에서 앞 글자만 쳐도 찾음 |
| **03 방제 물품·장비 찾기** | 「업체 섭외」(수집·운반 · 중간처분 · 종합재활용 · 최종처분(매립) · 중장비 · 독성가스 · 폐수 수탁처리) / 「방제물품 찾기」(흡착포·보호구 등 표준 27가지) 중 고르고 사고지점을 넣으면 가까운 순으로 **연락처 · 보유 수량**. **미리 협의된 업체는 맨 위**. 여러 곳을 동원 목록에 담아 한꺼번에 복사 |
| **04 현장 안전거리 확인** | 물질 · 사고지점 · 유출 규모(사람이 고름) · 바람(나침반)을 넣으면 **초기이격거리(둘레 원)** 와 **방호활동 구역(바람 따라 퍼지는 쪽)** 을 그림. 「내 위치 확인」을 켜면 움직이는 동안 구역 안인지 계속 표시 · 지도를 누르면 그 자리도 확인 · 규모·낮·밤별 거리 표 · **「상황 공유」 링크** · 01·02로 이어 가기 |

### 2026년 9월(AI프렌즈 결과 제출) 이후 새로 더하고 고친 것

- **04 현장 안전거리 확인 — 새 기능**(현장에 나간 사람 본인의 안전거리)과 **상황 공유 링크**
- **휴대전화 화면 다듬기** — 만족도 조사 뒤. 한 줄 머리띠 · 목록이 아래에 있다는 안내 · 지도 첫 화면 · 버튼 줄 맞춤
- **물질정보 읽기 개선(네 기능 공통)** — 원문의 항목 표시마다 줄을 나눠 읽기 쉽게(글자는 한 자도 바꾸지 않음) · 물질 칸을 다시 누르면 새로 찾기

## 5. 다른 기관에서 쓰기 — 확산

- **전국 자료** — 대피장소·임시주거시설·방제자원 모두 전국 단위입니다. 어느 시·군·구에서도 바로 쓸 수 있습니다.
- **정적 파일뿐** — 서버·DB·빌드 도구·외부 라이브러리가 없습니다. 아무 웹 서버(기관 홈페이지, Pages 서비스)에
  폴더째 올리면 끝입니다. `python3 build/make_release.py` 가 **개인정보 검사를 통과한 배포 폴더**와 업무망용 단일 파일을 만듭니다.
- **자료 갱신이 스크립트 한 줄** — 원자료를 바꾸고 스크립트를 다시 돌리면 화면 자료가 새로 만들어집니다.
  이재민 임시주거시설은 행정안전부 재난안전데이터공유플랫폼 **오픈API**로 받습니다(`build/fetch_tempshelter.html` — 인증키는 각 기관의 것을 넣음).
- **오래된 행정망 브라우저에서도** — 화면 코드는 ES5 문법(화살표 함수·let 없음)으로 썼습니다.
- **같은 틀로 다른 재난에** — 지도 엔진(`assets/mapcore.js`)과 "사고지점 → 가까운 순 → 연락처" 흐름은 자료만 바꾸면
  다른 재난·시설 찾기에도 그대로 쓸 수 있습니다.

```bash
python3 build/make_resources2.py  # 방제자원 통합 표(docs/방제자원_정리/통합) → data/resources2.js
python3 build/build_single.py     # 업무망 PC용 단일 파일 → dist/
python3 build/make_release.py     # 다른 기관에 넘길 배포 폴더(개인정보 검사)
tests/run.sh                      # 화면 자동 검증 20묶음
```

대피장소·물질정보의 원자료(`source/` · 기관 엑셀)는 이 묶음에 넣지 않았습니다 — 받은 원자료를 `source/` 에 두고
`python3 build/make_data.py` 를 돌리면 `data/` 가 다시 만들어집니다(openpyxl 필요).

## 6. 완성도 — 검증

`tests/run.sh` 는 **실제 크로미움 브라우저를 띄워 사람처럼 화면을 누르고** 결과를 확인합니다
(Node.js + Playwright 필요 · 구동 자체에는 필요 없음).

- **20묶음 · 1,023개 항목 + 휴대전화 화면 65개 점검 — 이 묶음 그대로 돌려 모두 통과**(2026-11-10). 묶음별 내용은 [검증 결과](docs/검증결과.md).
- 예: 물질 460종 ERG 거리 전수 대조 · 내 위치가 공유 링크에 들어가지 않는지 · 320~820px 화면에서 가로 밀림·겹침 ·
  손가락 크기(40px) · 고대비 두 모드의 색 · 자바스크립트를 꺼도 첫 화면 동작 · 업무망 단일 파일이 바깥 파일을
  부르지 않는지 · 임시주거시설 **만 곳 규모**에서 지도가 버티는지 · 리다이렉트하는 실제 서버에서 카드를 눌러 들어가지는지

## 8. 인터넷이 있을 때만 더해지는 것 · 알려진 제약

- 배경지도(브이월드 → 안 되면 OpenStreetMap 자동 전환) · 주소·장소 검색(브이월드) · 도보 경로(OSRM).
  없으면 그 기능만 빠지고 **행정경계선 위에서 나머지는 그대로** 동작합니다.
- 04의 구역은 **확산 모델링이 아니라 물질정보에 적힌 ERG 참고 거리**를 그린 것입니다. 바람·지형·용기 크기에 따라
  실제와 다를 수 있다고 화면 자료 출처에 적었습니다. 바람 방향을 고르지 않으면 거리만 점선 원으로 보여 줍니다.
- 이재민 임시주거시설 원자료에는 관리기관·전화가 없어 비워 둡니다(지어 넣지 않음).
- 행정경계선은 통계청 센서스용 경계(2018) 단순화본으로 법적 경계가 아닙니다.
