업무도구 세 가지 — 카드를 눌러 들어갑니다

01방제 물품·장비 찾기

필요한 물품·장비를 가진 곳을 사고지점 가까운 순으로 찾습니다.

  1. 필요한 것을 고릅니다 (여러 개 가능)
  2. 사고지점을 넣습니다 — 주소·사업장 이름 / 지도에서 찍기 / 내 위치
  3. 목록에서 거리·보유 물품·전화번호 확인
02주민 대피장소 찾기

사고지점 주변 대피장소를 거리·도보시간과 함께 찾습니다.

  1. 위쪽 ‘사고지점 찍기’ 또는 ‘내 위치’
  2. 목록에서 수용인원·주소·관할부서 전화 확인
  3. ‘이 내용으로 주민대피 문자 만들기’ 로 03 에 값 전달
03주민대피 문자생성기

사고 정보를 넣으면 재난문자 표준문안이 만들어집니다.

  1. 실내대피 / 도로 우회 / 주민소산 중 하나를 고릅니다
  2. 걸음마다 칸을 채웁니다 (위 진행 표시를 눌러 건너뛰어도 됨)
  3. ‘복사’ 를 눌러 문자발송시스템에 붙여 넣기

바탕화면(홈 화면)에 놓기 — 처음 한 번만

업무용 PC 크롬으로 주소 열기 → 오른쪽 위 ⋮ → 저장 및 공유 → 바로가기 만들기
엣지는 ··· → 앱 → 이 사이트를 앱으로 설치

아이폰 사파리로 주소 열기 → 아래쪽 공유 단추(□↑) → 홈 화면에 추가
크롬이 아니라 사파리여야 합니다
꼭 기억할 것
  • 이 도구는 판단하지 않습니다. 어디까지 대피시킬지는 담당자가 정하고, 최종 판단과 책임은 관계기관에 있습니다.
  • 거리는 직선거리, 도보·차량 시간은 어림값입니다.
  • 지도의 반경 원은 참고 거리이며 확산 모델링이 아닙니다.
  • 업체는 폐업하고 담당자는 바뀝니다 — 연락 전 확인.

잘 안 될 때

주소가 안 열림 업무망에서 외부 인터넷이 막힌 경우입니다. 휴대전화(LTE)로 열어 보시고, 안 되면 망분리PC용 단일파일을 쓰세요.
지도에 선만 보임 배경지도만 못 받은 것으로 거리·목록은 정상입니다. 위쪽 ‘조건 더보기’ 에서 배경지도를 바꿔 보세요.
‘내 위치’ 안 됨 위치 사용을 물었을 때 허용을 눌러야 합니다. 대신 지도에서 직접 찍기를 쓰세요.
문안이 안 만들어짐 필수 칸이 비면 일부러 만들지 않습니다(반쪽 문안 발송을 막기 위해). 비어 있는 걸음을 알려 주니 그 단추를 누르세요.
