바탕화면에 아이콘 만들기

처음 한 번만
PC
  1. 크롬 · 엣지 열기
  2. 주소 입력
  3. 오른쪽 위 ⋮ → 바로가기 만들기
안드로이드
  1. 크롬 열기
  2. 주소 입력
  3. 오른쪽 위 ⋮ → 홈 화면에 추가
아이폰
  1. 사파리로 열기 (크롬 ✗)
  2. 주소 입력
  3. 아래 공유 ⬆ → 홈 화면에 추가

다음부터는 아이콘만 누르면 열립니다. 인터넷 익스플로러에서는 화면이 깨집니다.
