# 새 방제자원을 ③ 도구에 어떻게 녹일까

정리한 자료(`README.md`)를 **③ 방제 물품·장비 찾기**에 넣는 방안입니다.
아직 아무것도 반영하지 않았습니다 — **고르시면 그때 만듭니다.**

---

## 0. 먼저 알아야 할 것 — 자료가 5.5배가 됩니다

| | 지금 | 새 자료를 넣으면 |
|---|---:|---:|
| 지도에 찍히는 지점 | **470** | **1,141** (1차) → **2,571** (지정폐기물까지) |
| 자원 종류 | 6 | 그대로 6 (아래 1절) |
| 필요한 것(걸음 1) | 7 | 8 (인력 지원 추가) |

**이것이 이 작업의 가장 큰 위험입니다.** 지금은 470건이라 사고지점을 넣으면
전국이 한 화면에 들어옵니다. 2,571건이 되면 **가까운 순으로 늘어놓기만 해도
화면이 넘칩니다.** 그래서 아래 2절(좁히기)이 자료를 넣는 것보다 중요합니다.

---

## 1. 자원 종류는 6개를 **그대로 두되, 뜻을 바꿉니다**

지금 6종은 자료 출처로 나뉘어 있습니다(지자체·비상캡슐·독성가스·폐기물·해경·
수질센터). 새 자료를 넣으면 출처가 10가지가 되어 **색과 아이콘을 4개 더
만들어야 하고**, 지도에 색 동그라미가 10가지가 됩니다 — 구분이 안 됩니다.

대신 **"누구에게 어떻게 부르는가"** 로 다시 묶으면 6개로 끝납니다.
담당자가 실제로 하는 질문이 그것이기 때문입니다.

| 새 종류 | 무엇 | 건수 | 동원하는 법 |
|---|---|---:|---|
| ① 우리 지자체가 가진 것 | 시·군·구 부서 보유 장비 | **437** | 내부 협조 — 가장 빠름 |
| ② 우리가 부를 수 있는 업체 | 관할 중장비·폐기물 업체 | **496** | 전화 요청 (계약·협약) |
| ③ 현장에 놓여 있는 장비함 | 산단·고속도로 방제장비함 | **48곳** | 가서 여는 것 · 관리주체에 통보 |
| ④ 사업장이 가진 것 | 화학안전공동체 사업장 | **106** | 사업장에 협조 요청 |
| ⑤ 국가기관 비축·전문기관 | 해경 비축기지 3 · 방제정 25 · 수질센터 4 | **32** | 공식 요청 — 시간이 걸림 |
| ⑥ 특수 대응 자원 | ERaCV 19 · 중합방지제 3 · 독성가스 회수 2 | **24** | 전국에 몇 곳뿐 — 먼저 확인 |

> 색·아이콘은 지금 것을 그대로 씁니다. `tests/res2` 가 범례 색과 마커 색을
> 대조하고 있어 **색을 늘리면 그 검증부터 다시 써야 합니다.**
> 지정폐기물 1,430곳은 ②에 들어갑니다(행 단위 정리가 끝난 뒤).

## 2. 걸음 1 '필요한 것' — 7개에 하나만 더합니다

지금 7갈래는 그대로 맞습니다. 새 자료도 대부분 여기에 붙습니다.

| 필요한 것 | 지금 | 새로 붙는 것 |
|---|---:|---|
| 차량·중장비 | | + 관할 중장비 업체 **166곳** (암롤트럭 109·덤프 76·카고 66·집게차 24·굴착기 27·탱크로리 16) |
| 보호구 | | + 방제장비함 48곳(내화학장갑·전면형 방독면·화학보호복 3형식) + 사업장 106곳 |
| 중화제·흡착재 | | + 방제장비함(유흡착제·흡착포) + 사업장 + 수질센터 케미컬흡착재 |
| 봄베 밀봉 | 19 | 그대로 |
| 가스 회수 | 2 | 그대로 (hwp 를 못 읽어 더 못 채웠습니다 — 4절) |
| 폐기물 처리 | 15 | + 관할 폐기물업체 **330곳** + 지정폐기물 **1,430곳** |
| 대량 비축 | 3 | + 해경 방제정 25척 · 수질센터 4권역 |
| **인력 지원** ← 새로 | – | 사업장 방재인원 **68곳** (금호석유화학 여수정밀화학 122명 등) |

**'인력 지원'을 왜 더하나** — 현장에서 모자란 것은 물건만이 아닙니다.
자료에 **사업장별 방재인원 수가 실제로 들어 있습니다**(77행). 있는 자료를
안 보여 줄 이유가 없습니다. 다만 **사람은 물건과 다릅니다** — "몇 명 있다"가
"보내 준다"는 뜻이 아니므로, 카드에 그렇게 적어야 합니다.

**중합방지제는 '중화제·흡착재'에 넣습니다.** 갈래를 하나 더 만들 만큼
건수(3곳)가 많지 않고, 급할 때 8개도 이미 많습니다.

## 3. 목록이 넘치지 않게 — 이것이 제일 중요합니다

건수가 5배가 되면 **지금 화면 그대로는 못 씁니다.** 세 가지를 함께 해야 합니다.

### (1) 반경을 먼저 좁히고 시작합니다
지금은 전국을 거리순으로 늘어놓습니다. **기본 30km** 안만 보여 주고,
없으면 이미 있는 **'범위 넓히기'** 단추로 넓힙니다(`tests/widen` 이 이미
검증하는 기능입니다). 화학사고 초동대응에서 100km 밖 업체는 답이 아닙니다.

### (2) 종류마다 '가장 가까운 몇 곳'만 펴 놓습니다
6종을 한 줄로 섞어 거리순 정렬하면, 폐기물업체 1,430곳이 앞을 다 차지해
**정작 우리 지자체 장비가 30번째에** 갑니다. 종류별로 접어 두고 각 3곳씩만
펴 두는 편이 낫습니다.

### (3) 업종 이름을 묶습니다
지금 `03` 의 업종 표기는 **19가지**입니다 —
`폐기물 수집∙운반업체` / `폐기물수집운반업` / `수집운반업` /
`지정폐기물 수집운반업체` 가 따로 있습니다. 사용자는 같은 것을 네 번 봅니다.
**4가지로 묶습니다**: 수집·운반 / 중간처분 / 최종처분(매립) / 재활용,
그리고 중장비는 따로.

## 4. 넣기 전에 반드시 해결해야 하는 것

### ⚠ (1) 좌표가 하나도 없습니다 — 이게 가장 큰 일
새 자료 **1,141곳 전부 주소 문자열뿐**입니다. 지금 서비스의 470건도
**정확한 좌표는 0건**이고 시·군·구나 읍·면·동으로 어림잡은 값입니다
(`sgg` 276 · `emd` 95 · `road` 73 · `sido` 19).

- 어림값이 늘어나면 **"가까운 순"이 틀리기 시작합니다.** 시·군·구 중심으로
  찍힌 두 업체는 거리가 같게 나옵니다.
- 해결: `build/geocode.html`(이미 있음)을 인터넷 되는 PC에서 돌려
  브이월드로 도로명주소 → 좌표를 받습니다. **1,141건이면 하루 안에 됩니다.**
- ⚠ 브이월드 인증키의 **활용 도메인 등록**이 필요합니다. 지금 시범운영
  링크가 닫혀 있어 이 절차도 함께 정리해야 합니다.

### ⚠ (2) 자료 기준일이 기관마다 다릅니다
금강청 **2024-12** ↔ 낙동강청 **2026-01** — 1년 넘게 차이납니다.
지금은 화면에 기준일을 **하나만** 적는데, 그대로 두면 거짓이 됩니다.
→ **건마다 기준일을 달고**, 카드에 "이 자료 ○○○○-○○ 기준"으로 적습니다.

### (3) 전화번호가 없는 곳이 19%
`03` 763행 중 **148행에 대표번호가 없습니다.** 기존 규칙대로
**기관 이름만 적고 번호는 비웁니다**(지어내지 않습니다).

### (4) 못 읽은 파일이 남아 있습니다
`.hwp`/`.hwpx` **6건**, 구형식 `.xls` **1건**, 155MB PDF **1건**.
특히 **`전국 독성가스 처리업체.hwp`** 는 지금 '가스 회수' 갈래가 2건뿐인
이유입니다. **xlsx 나 CSV 로 다시 받으면** 그 갈래가 채워집니다.
→ 사용자께 요청드릴 것: 이 8개 파일을 엑셀로 저장해 주시면 바로 넣겠습니다.

## 5. 독성가스 취급사업장 1,579곳 — 자원 목록에 넣지 마세요

`06` 은 **사고가 날 수 있는 곳**이지 도움을 받는 곳이 아닙니다.
자원 목록에 섞으면 담당자가 사고 현장으로 지원 요청을 겁니다.

대신 **훨씬 값어치 있는 쓰임이 두 개** 있습니다.

### (1) 사고지점을 '사업장 이름'으로 찍기 — 걸음 2가 빨라집니다
③의 걸음 2는 지금 사고지점을 **주소·좌표·지도 찍기**로 받습니다.
현장에서 처음 들어오는 정보는 대개 **"○○화학에서 났다"** 는 사업장 이름
입니다. 이 1,579곳(주소 포함)을 **검색 후보로만** 넣으면, 이름을 치는 순간
사고지점이 잡힙니다. **지도에는 찍지 않고 검색에만 씁니다.**

### (2) ① 문자생성기의 '사고물질' 칸 채우기
자료에 사업장별 **취급 물질(256종)과 CAS번호**가 있습니다.
사업장을 고르면 그 사업장이 다루는 물질이 후보로 뜹니다 —
급할 때 물질명을 잘못 적는 일을 줄입니다.
(상위: 암모니아 1,774건 · 염소 400건 · 모노실란 196건 · 산화에틸렌 130건)

> ⚠ 다만 **"이 사업장에서 이 물질이 샜다"고 단정하지 않습니다.** 허가받은
> 물질일 뿐입니다. 화면에는 "이 사업장이 취급 허가를 받은 물질"이라고
> 적어야 합니다(CLAUDE.md 2절 5항).

## 6. 이 순서로 하시길 권합니다

| | 무엇 | 왜 이 순서인가 | 드는 일 |
|---|---|---|---|
| **1차** | `01` 지자체 장비 갱신 + `03` 관할 업체 496곳 | 담당자가 **가장 먼저 부르는 곳**이고, 지금 서비스에 아예 없습니다 | 좌표 496건 |
| **2차** | `04` 장비함 48곳 + `05` 사업장 106곳 | 현장에 실제로 물건이 있는 곳. 건수가 적어 목록을 안 망칩니다 | 좌표 154건 |
| **3차** | `06` 을 **사고지점 검색 후보**로 (지도에는 안 찍음) | 걸음 2가 빨라집니다. 지도 부담이 없습니다 | 좌표 불필요 |
| **4차** | `12` 지정폐기물 1,430곳 | 건수가 가장 크므로 **3절(좁히기)을 먼저 끝낸 뒤** | 유역청 7곳 재취합 + 좌표 1,430건 |
| **5차** | 해경 방제정 25 · 인력 지원 갈래 | 쓰임이 좁아 마지막 | 적음 |

**1·2차만 해도 470건 → 1,141건**이 되고, 그 사이에 3절의 좁히기를 검증할 수
있습니다. 한 번에 다 넣으면 무엇 때문에 느려졌는지 못 찾습니다.

## 7. 정하고 넘어가야 할 것 — 사용자 확인 사항

1. **자원 종류 6개를 '동원하는 법'으로 다시 묶는 것**(1절)에 동의하시는지.
   지금 분류를 그대로 두고 종류를 10개로 늘리는 길도 있습니다.
2. **'인력 지원' 갈래를 넣을지**(2절). 사람을 자원으로 목록에 올리는 것이
   기관 입장에서 부담이라면 빼겠습니다.
3. **독성가스 사업장을 검색 후보로 쓰는 것**(5절)에 동의하시는지.
   1,579곳의 상호·주소가 도구 안에 들어갑니다(모두 공개 자료입니다).
4. **못 읽은 8개 파일**을 엑셀로 다시 받을 수 있는지(4절 4항).
5. **대구청 지정폐기물** 자료를 다시 받을 수 있는지.
