기관마다 양식이 달라 한 파일 안에 표가 여러 개 들어 있거나 칸 수가 중간에

지금 서비스에 들어 있는 방제자원은 **470건**인데, 이 자료로 **1,141곳**을
바로 채울 수 있고, 지정폐기물 업체까지 넣으면 **약 2,570곳**이 됩니다.

⚠ 원자료에는 **담당자 실명 2,480건 · 개인 휴대전화 495건 · 사업자등록번호

(`표/99_개인정보_제거현황.csv`). 기관·사업장 **대표번호만** 남겼습니다.

## 3. 자료의 상태 — 그대로 쓰면 안 되는 것들

정리하면서 실제로 걸린 것만 적습니다.

1. **개인정보가 곳곳에 있습니다.** 특히 `읍면 방제장비 및 중장비업체 현황`
   (진천군)은 **연락처가 전부 개인 휴대전화**라 걷어내면 남는 것이 이름뿐
   입니다. 이 파일은 정리본에 넣지 않았습니다.
2. **좌표가 하나도 없습니다.** 전부 주소 문자열뿐입니다. 지도에 찍으려면
   지오코딩이 필요합니다(현재 서비스도 주소로 어림잡고 있고, 470건 중
   **정확한 좌표는 0건**입니다).
3. **업종 이름이 제각각입니다.** `03`의 업종만 봐도 `폐기물 수집∙운반업체` /
   `폐기물수집운반업` / `수집운반업` / `지정폐기물 수집운반업체` 가 따로
   있습니다(19가지). 묶어 주지 않으면 사용자가 같은 것을 네 번 봅니다.
4. **전화번호가 비어 있는 곳이 있습니다.** `03`은 763행 중 **148행(19%)**
   에 대표번호가 없습니다.
5. **자료 기준일이 기관마다 다릅니다.** 금강청 2024-12 ↔ 낙동강청 2026-01.
   화면에 한 날짜만 적으면 거짓이 됩니다.
6. **같은 파일이 여러 폴더에 중복**돼 있습니다(해경 비축기지는 3곳에
   같은 파일). `2-5. 민간 방제 선박.xlsx` 는 **이름과 내용이 다릅니다**
   — 열어 보면 해경 비축기지 자료입니다.
7. **못 읽은 파일이 있습니다** — `.hwp`/`.hwpx` 6건, `.xls`(구형식) 1건,
   155MB PDF 1건. 목록은 `00_원자료_목록.csv`.

## 4. 다시 만들려면

```bash
python3 build/방제자원_정리.py    # 원자료 → 표/*.csv
python3 build/방제자원_통계.py    # 표 → 통계.json
python3 build/방제자원_보기.py    # 표 → 한눈에보기.html
node   build/방제자원_보고서.mjs   # 발표용 한 장 보고서 PDF (한 쪽을 넘기면 멈춤)
```

원자료 원문은 개인정보 때문에 저장소에 넣지 않았습니다. 드라이브 파일 ID 는
`표/00_원자료_목록.csv` 에 적어 두었습니다.
