# 방제자원 통합 — 분류안(PPT)대로 두 갈래로 묶은 결과

사용자가 준 분류안(PPT · 2026-09-07)대로 표 18개를 **두 갈래**로 다시
묶었습니다. **서비스 자료(`data/`)는 아직 건드리지 않았습니다** — 이
폴더에서 확인한 뒤에 ③ 도구에 넣습니다.

```
python3 build/방제자원_통합.py       # 표 18개 → 업체.csv · 물품.csv
python3 build/방제자원_통합_보기.py   # → 한눈에보기.html (눌러 보는 검토 페이지)
```

| 파일 | 무엇 |
|---|---|
| `업체.csv` | **1,582곳** — 갈래·업체명·권역·시도·시군구·주소·대표전화·허가현황·처리가능폐기물·보유장비·자료출처 |
| `물품.csv` | **4,075줄** — 물품명·분류·원래이름·개수·단위·보유처·보유처종류·권역·시도·시군구·주소·대표전화·자료출처 |
| `업체_처리가능폐기물_없음.csv` | **885곳** — 분류안이 필수라고 못 박았는데 자료에 없는 것 |
| `물품_미분류이름.csv` | **25가지(51줄)** — 표준 이름으로 못 묶은 원자료 표기 |
| `통계.json` · `한눈에보기.html` | 수치 · 검토 페이지 |

## 1. 분류안을 어떻게 옮겼나

```
방제자원
├─ ① 업체 섭외      1,582곳
│    수집·운반 856 / 중간처분(소각) 24 / 중간처분(그 외) 39 /
│    종합재활용 464 / 최종처분(매립) 25 / 중장비 166 /
│    특수처리 2 / 기타 6
└─ ② 방제물품 찾기   4,075줄 · 표준 이름 84가지
     보호구 1,699 / 흡착·중화 1,191 / 차량·중장비 689 /
     작업도구 339 / 인력 87 / 특수 19 / 기타 51
```

**필수 항목은 분류안이 적은 것만** 올렸습니다(양식이 하나여야 한다는 것이
요구사항이라, 원자료에 있어도 그 밖의 칸은 통합표에 넣지 않았습니다).

- 업체 — ① 허가 현황 ② 처리가능물질 종류 ③ 연락처 ④ 주소
- 물품 — ① 자원명 ② 보유 개수 ③ 보유 업체·기관명 ④ 담당자 연락처

**권역** — 수도권 / 강원권역 / 충청권역 / 경상권역 / 전라권역 + 시·도.
시·도가 빠진 주소("여수시 연등1길 175")는 저장소의 공식 행정경계
자료(`data/boundaries.js` · 250개 시·군·구)로 되짚어 채웠습니다.
⚠ **제주는 분류안의 다섯 권역에 없어 전라권역에 넣었습니다** — 환경부
조직(영산강유역환경청이 제주 관할)과 표 09 의 '영산강(광주전남제주)'
묶음을 따른 **제 판단**이므로 확인이 필요합니다.

### 물품 이름을 왜 다시 붙였나

원자료의 물품 이름이 **한 표에서만 484가지**였습니다(표 05). 그대로 두면
분류안의 "사용자가 딱 원하는 물품만 확인"이 안 됩니다 — 방독면을 찾는
사람이 전면형마스크·반면형마스크·방독마스크를 따로 눌러야 합니다.

**표준 이름 84가지로 묶고, 원래 이름은 각 줄에 함께 남겼습니다**
(`원래이름`). 급할 때 필요한 것은 "화학물질 흡착포(패드형 100매)" 라는
원문이기 때문입니다. 묶는 규칙은 `build/방제자원_통합.py` 의 `물품사전`
한 곳에 모아 두었습니다 — 고칠 곳이 한 군데입니다.

## 2. ⚠ 아직 못 채운 것 — 넣기 전에 풀어야 합니다

### (1) 처리가능 지정폐기물 목록이 885곳에 없습니다 ← 가장 큰 구멍

분류안이 **"수집운반, 중간처분, 종합재활용, 최종처분 업체는 허가증 상에
처리가능한 지정폐기물 목록이 보여야 함"** 이라고 못 박은 항목입니다.

| 자료 | 행 | 처리가능 폐기물 |
|---|---:|---|
| 표 03 지자체 관할 폐기물·중장비 업체 | 763 | **있음** |
| 표 13 지정폐기물 처리업체(대구청) | 251 | **있음** |
| 표 14 폐기물처리업체 **전국취합** | 1,511 | **없음 — 칸 자체가 없습니다** |

업체명이 같으면 표 03·13 에서 옮겨 채웠습니다(561곳). 남은 **885곳**은
자료에 그 값이 없어 **비워 두었습니다**(지어내지 않았습니다).

→ 드라이브의 **`0. 폐기물 처리업체_협의 완료 업체`** 안에 허가증이 있을
것으로 보입니다(분류안에도 "허가증 내 처리가능 지정폐기물 필수 도출"이라고
적혀 있습니다). 그 파일을 받아야 채울 수 있습니다.

### (2) '중간처분(중화)' 을 가려낼 수 없습니다

원자료의 처리방법 값은 **소각·매립·재활용·수집운반·기타** 다섯뿐이고
**'중화'가 없습니다.** 중화 여부는 허가증을 봐야 나오는 값이라, 소각이
아닌 중간처분은 **`중간처분(그 외)`** 로 두고 처리방법 원문을 함께
적었습니다. 지어내서 '중화'라고 적지 않았습니다.

### (3) 드라이브 자료를 직접 읽지 못했습니다

`방제자원_정리` 폴더의 9건이 모두 **zip(37~137MB)** 과 **155MB PDF** 입니다.
드라이브 도구는 파일을 base64 로만 돌려주어 이 크기는 대화로 옮길 수
없습니다. 그래서 이번 통합은 **지난번에 이미 펴 둔 표 18개**(같은 원자료를
`docs/방제자원_정리/표/` 로 정리해 둔 것)를 썼습니다.

→ **zip 안의 엑셀·CSV 를 파일로 직접 붙여 주시면** 그 길이 훨씬 정확합니다
(`build/xlsx읽기.py` 가 칸 그대로 읽습니다). 특히 위 (1) 의 허가증 자료.
받은 파일은 개인정보가 들어 있어 저장소에 넣지 않고 `방제자원_보충`
환경변수가 가리키는 폴더에 둡니다.

### (4) 그 밖에

- **독성가스 회수업체 2곳** — 분류안의 여섯 갈래에 없어 `특수처리` 로 따로
  두었습니다. 어디에 넣을지 정해 주세요.
- **연락처 없음** — 업체 127곳 · 물품 759줄. 확인 못 한 번호는 기관·업체명만
  적고 비웠습니다(CLAUDE.md 2절). 개인 휴대전화는 기계가 검사해 하나라도
  있으면 파일을 만들지 않습니다.
- **개수 모름** 108줄 — 원자료에 수량 칸이 없던 것입니다.
- **표 15(전남·광주 방제약품)는 자료 기준이 2017년**입니다.
- **못 묶은 이름 25가지** — 원자료 자체가 뭉뚱그린 것("방제장비"·"소형"·
  "처리능력"·"물 적재량")이라 `기타` 로 두었습니다.
- **좌표가 없습니다.** 지도에 찍으려면 주소 → 좌표 변환이 필요합니다
  (업체 1,581곳 · 물품 3,901줄에 주소가 있습니다). 이 개발 환경은 바깥으로
  못 나가므로 `build/geocode.html` 을 인터넷 되는 PC 에서 한 번 돌리는
  방식입니다(CLAUDE.md 6절).

   그 7갈래와 어떻게 이어질지 사용자와 먼저 맞춰야 합니다.
