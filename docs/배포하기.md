# 지자체에 링크 하나로 나눠 주기

시범운영을 위해 **압축파일 대신 주소 하나**를 건네는 방법입니다.
받는 사람은 그 주소를 열기만 하면 되고, 원하면 바탕화면 아이콘으로도
놓을 수 있습니다.

이 문서는 개발자가 아닌 사람이 따라 할 수 있게 적었습니다.

---

## 0. 먼저 알아 둘 것 — 지금도 링크는 있습니다

저장소에 `.github/workflows/pages.yml` 이 있어서, 작업 가지에 밀어 넣을
때마다 **이미 자동으로 사이트가 올라가고 있습니다.**

    https://rlawogns221221221-create.github.io/nics_chem-safety-cheatkey/

지금 이 주소는 열립니다. 다만 **주소에 깃허브 계정 이름과 저장소 이름이
그대로 보입니다.** 지자체에 나눠 줄 시범운영 링크로는 맞지 않습니다.
아래 셋 중 하나로 옮기면 그 이름이 사라집니다.

---

## 1. 어디에 올릴까 — 세 가지 길

| | 길 | 주소가 이렇게 됩니다 | 계정이 보이나 | 비용 | 걸리는 시간 |
|---|---|---|---|---|---|
| 가 | **기관 웹서버** | 기관이 정한 주소 | 안 보임 | — | 기관 절차에 따름 |
| 나 | **Cloudflare Pages** (직접 올리기) | `이름.pages.dev` | 안 보임 | 무료 | 5분 |
| 다 | GitHub Pages + 도메인 구입 | 산 도메인 주소 | 안 보임 | 도메인값 | 30분 + DNS 반영 |

**시범운영이라면 (나) 를 권합니다.** 깃허브와 아무 상관이 없고,
폴더를 끌어다 놓으면 끝이며, https 도 저절로 붙습니다.
정식 서비스로 갈 때 (가) 로 옮기면 됩니다 — 올리는 파일은 똑같습니다.

### 무엇을 올리나 — 폴더 하나

    python3 build/make_release.py

를 돌리면 `release/화학사고_초동대응_지원_서비스/` 폴더가 생깁니다
(파일 42개 · 3.8MB). **이 폴더를 통째로** 올립니다.
서버 프로그램(PHP·Node 등)은 필요 없습니다 — 파일만 있으면 됩니다.

> 폴더 안의 파일들은 서로를 상대경로로 부릅니다.
> **파일 하나만 따로 옮기면 화면이 깨집니다.** 구조를 그대로 두세요.

### 나) Cloudflare Pages — 직접 올리기

1. <https://dash.cloudflare.com> 에서 계정을 만듭니다(무료).
2. 왼쪽에서 **Workers & Pages → Create → Pages → Upload assets** 를 고릅니다.
3. 프로젝트 이름을 적습니다. **이 이름이 주소가 됩니다.**
   예를 들어 `chem-first-response` 라고 적으면
   `https://chem-first-response.pages.dev` 가 됩니다.
   (한글은 안 되고 영문 소문자·숫자·붙임표만 됩니다)
4. `release/화학사고_초동대응_지원_서비스/` 폴더를 통째로 끌어다 놓습니다.
5. **Deploy** 를 누르면 몇십 초 뒤 주소가 나옵니다. 그 주소를 나눠 주면 됩니다.

자료를 고쳐 다시 올릴 때도 같은 자리에서 폴더를 다시 올리면 됩니다.
주소는 그대로입니다.

### 다) GitHub Pages 를 그대로 두고 주소만 바꾸기

이미 자동 배포가 되고 있으므로, 도메인(예: `화학사고초동대응.kr`)을 사서
저장소 **Settings → Pages → Custom domain** 에 넣으면 그 주소로 열립니다.
계정 이름은 주소에서 사라집니다. 다만 **저장소 자체는 공개된 상태**이므로,
소스까지 감춰야 한다면 (나) 나 (가) 로 가야 합니다.

## 2. 올린 뒤에 꼭 확인할 것 두 가지

### ① https 인가

`http://` 로 올리면 브라우저가 **‘내 위치 찾기’를 막고**, 바탕화면 아이콘
설치도 되지 않습니다. 현장에 나간 담당자가 실제로 쓰는 기능입니다.
Cloudflare Pages·GitHub Pages 는 https 가 저절로 붙습니다. 기관 서버에
올릴 때만 확인하면 됩니다.

### ② 브이월드 인증키에 새 주소를 등록했는가

배경지도(도로·건물)는 국토교통부 브이월드에서 받아옵니다.
<https://www.vworld.kr> → 오픈API → 인증키 발급 → **활용 도메인**에
올린 주소를 넣고, 받은 키를 `data/basemap.js` 의 `인증키` 값에 넣으세요.

등록 전에도 화면은 정상입니다 — 브이월드가 거부하면 OpenStreetMap 으로
자동으로 넘어갑니다. 다만 국내 지명 표기는 브이월드가 낫습니다.

## 3. 바탕화면 아이콘 — 지자체 담당자에게 그대로 보낼 안내문

아래를 복사해 공문·메신저에 붙여 쓰시면 됩니다.
(⟨주소⟩ 자리에 실제 주소를 넣으세요)

> **화학사고 초동대응 지원 서비스 — 사용 안내**
>
> 아래 주소를 열면 바로 쓸 수 있습니다. 설치할 프로그램은 없습니다.
> ⟨주소⟩
>
> **바탕화면에 놓고 쓰려면**
> - **안드로이드 휴대전화** — 주소를 크롬으로 연 뒤, 화면 아래쪽에 나오는
>   **‘바탕화면에 추가’** 를 누르세요. 안 보이면 오른쪽 위 ⋮ →
>   ‘홈 화면에 추가’ 입니다.
> - **아이폰·아이패드** — 주소를 **사파리**로 연 뒤, 아래쪽 공유 단추(□↑)
>   → **‘홈 화면에 추가’** 를 누르세요.
>   (크롬이 아니라 사파리로 열어야 합니다)
> - **업무용 PC** — 크롬이나 엣지로 연 뒤, 화면 아래쪽 **‘바탕화면에 추가’**
>   또는 주소창 오른쪽 끝의 설치 아이콘(⊕)을 누르세요.
>
> 이렇게 하면 앱처럼 아이콘 하나로 바로 열리고, **인터넷이 잠깐 끊겨도
> 화면이 뜹니다**(한 번 연 뒤부터). 다만 끊긴 동안에는 배경지도·주소검색이
> 나오지 않습니다.

## 4. 알아 둘 것 — 솔직하게

### 주소를 아는 사람은 누구나 볼 수 있습니다

로그인이 없습니다. 지자체에만 보이게 하려면 별도의 인증이 필요한데,
그것은 정적 사이트로는 안 되고 서버가 있어야 합니다.
지금 올라가는 자료에 **개인정보는 없습니다**(담당자 이름·휴대전화 없음,
사업장 대표번호만). `make_release.py` 가 기계로 검사해 하나라도 걸리면
폴더를 만들지 않습니다. 그래도 **공개해도 되는 자료인지는 원내 확인이
필요합니다.**

### 행정망(업무망) PC 에서는 막힐 수 있습니다

지자체 업무망은 바깥 인터넷을 막아 두는 곳이 많습니다. 그때는 링크가
열리지 않습니다. 그런 자리를 위해 **파일 하나로 도는 판**을 함께 만듭니다 —
`release/망분리PC용_단일파일/` 안의 HTML 세 개입니다. USB·공유폴더로 옮겨
브라우저로 열면 됩니다(배경지도·주소검색만 빠지고 나머지는 그대로).

### 자료를 고쳤을 때

1. `python3 build/make_release.py` 로 폴더를 다시 만들고
2. 그 폴더를 같은 자리에 다시 올립니다.

이미 바탕화면에 깔아 둔 사람에게는 **다음에 열 때** 반영됩니다.
한 번에 확실히 갈아 끼우려면 `sw.js` 맨 위의 `var 버전 = "v1"` 을
`"v2"` 처럼 올리세요.

## 5. 바탕화면 아이콘은 어떻게 만들어져 있나 (개발자용)

| 파일 | 무엇 |
|---|---|
| `manifest.webmanifest` | 앱 이름·아이콘·시작 주소. **사이트 뿌리에 있어야** 합니다 |
| `sw.js` | 인터넷이 끊겨도 열리게 하는 것. **사이트 뿌리에 있어야** 합니다 |
| `assets/pwa.js` | 위 둘을 등록하고, 기기에 맞는 설치 안내를 답니다 |
| `build/icon.svg` | 아이콘 원본 |
| `build/make_icons.mjs` | 원본 → `assets/img/icon-192·512·180.png` |

- **뿌리에 있어야 하는 이유** — 서비스워커는 자기가 놓인 폴더까지만
  맡습니다. `assets/` 안에 두면 `sms/`·`map/`·`res/` 가 관할 밖이 되어
  도구 세 개가 오프라인에서 열리지 않습니다.
- **주소를 상대경로(`./`)로 적은 이유** — 어느 서버의 어느 폴더에 올려도
  그대로 동작해야 합니다. 뿌리(`/`)로 적으면 하위 폴더에 올린 순간
  아이콘·설치가 통째로 깨집니다.
- **아이콘을 바꾸려면** `build/icon.svg` 를 고치고
  `node build/make_icons.mjs` 를 돌리세요.
  지금 그림은 파란 바탕에 흰 경고 삼각형입니다. 정부상징(태극)을 넣지
  않은 것은 의도적입니다 — 기관의 공식 표장을 아이콘에 넣는 것은
  "공식 앱"이라는 주장이라 기관 승인이 필요합니다.
- **검증** — `tests/run.sh pwa` 가 진짜 웹서버를 띄워 서비스워커 등록·
  오프라인 열기·설치 안내·단일 파일에 안 섞였는지까지 확인합니다.
