이재민 임시주거시설 자료 받기

한 번만 돌리면 됩니다. 결과 파일을 data/ 에 넣으면 ② 대피장소 지도에 이재민 임시주거시설이 화학사고 대피장소와 별개의 층으로 함께 나옵니다.

왜 이렇게 받나
자료를 만든 자리(개발 환경)에서는 공공데이터포털 서버에 닿지 않습니다. 그래서 인터넷이 되는 PC에서 이 페이지를 열어 받아 오고, 만들어진 data/tempshelters.js 파일만 저장소에 넣는 방식으로 합니다. 자료가 갱신되면(보통 1년 단위) 이 페이지를 다시 돌리면 됩니다.

1. 자료 주소와 인증키

인증키는 이 브라우저에만 저장되고(localStorage) 저장소 파일에는 들어가지 않습니다. 인증키를 저장소·메일로 돌리지 마세요.

기다리는 중

2. 제대로 읽었는지 확인

원자료의 칸 이름을 아래처럼 짝지었습니다. 빠진 항목이나 엉뚱하게 짝지어진 것이 있으면 그대로 알려 주세요 — 규칙을 고치면 됩니다.

3. 파일 받기

받은 tempshelters.js 를 저장소의 data/ 폴더에 넣으세요. 넣고 나서 python3 build/build_single.py 를 다시 돌리면 망분리 PC용 단일 파일에도 함께 들어갑니다.

서버에 닿지 않을 때

  1. 브라우저 주소창에 아래를 붙여넣어 JSON 이 나오는지 먼저 봅니다.
    자료주소?page=1&perPage=10&serviceKey=인증키
  2. JSON 은 나오는데 이 페이지에서만 실패하면 브라우저 보안(CORS) 때문입니다. 주소창에서 perPage=99999 로 열어 Ctrl+S 로 저장한 뒤, 위의 내려받아 둔 JSON 파일로 하기 로 그 파일을 고르세요. 결과는 같습니다.
  3. SERVICE_KEY_IS_NOT_REGISTERED_ERROR 가 나오면 포털에서 그 활용신청이 승인됐는지, Decoding 키를 넣었는지 확인하세요.
